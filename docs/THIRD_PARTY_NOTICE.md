The ECU mutation fixtures contain selected source from Speeduino and rusEFI, with deliberate educational statements inserted for static-analysis evaluation. Upstream license files are included in each redistributed baseline/mutant ZIP. Original copyright and license notices in source files remain intact.

The experiment does not claim that upstream projects contain the injected defects. Do not compile these fixtures into vehicle firmware or flash them to hardware. The provenance records identify source repositories, snapshot roots, hashes and changed functions. Read each upstream license before reusing or redistributing source.

The public benchmark downloads source snapshots to the ignored local benchmark_cache directory. Published benchmark records retain hashes and candidate locations rather than redistributing entire source trees. Public discovery does not imply endorsement by any upstream project.
